    No account found. Why isn't it marked available?+

    Profile lookup and name availability are separate checks. A successful lookup can return no account while Twitch blocks the availability check. In that case, we show “No account found” and “Availability: Not verified”. Only an explicit availability response lets us mark a name available.

    How do I confirm I can use a name?+

    Check it in Twitch Sign Up, or go to Settings → Profile to edit your username if you already have an account. A name without a visible profile may still be withheld or restricted. See Twitch's username policy ↗. Availability can change before you claim it.

    Do I need to sign in here?+

    No. This tool does not ask for your password or account access. The username is sent directly to Twitch. Recent searches stay in this browser and can be cleared at any time.
