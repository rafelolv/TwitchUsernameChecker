# Contributing

Read [AGENTS.md](AGENTS.md) and [maintenance](docs/MAINTENANCE.md). Explain the
observable problem, keep changes focused and edit canonical source directly.
Use Node.js 24 and run `npm run check`. No dependency installation is required.

For UI/integration changes, include browser scenarios, versions and viewports.
Separate simulated results from live Twitch queries and state untested cases.
Never include credentials, private history or raw responses.

Use English for all project documentation, comments, user-facing text, metadata,
and commit messages.
Record concise user-visible changes in [CHANGELOG.md](CHANGELOG.md).
Documentation-only changes need no version bump. Keep the site static, accessible
and independent from the maintainer's other apps.

The project is licensed under [MIT](LICENSE). Contributions intentionally
submitted for inclusion are provided under the same license unless a different
arrangement is explicitly agreed in advance. Preserve required copyright and
permission notices.
