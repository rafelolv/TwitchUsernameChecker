# Twitch Username Checker 1.0.0

First public release: a small, independent nickname checker with a Brazilian
Portuguese interface and a responsive cream/purple design.

## Changes

- Look up Twitch profiles and display taken, available, unavailable or unconfirmed
  based on the actual response.
- Keep six recent searches locally and recheck names when selected.
- Validate nicknames before requests and handle failures, timeouts and rate limits.
- Provide static GitHub Pages deployment, MIT licensing and maintenance guides.

## Use and installation

The hosted site is intended for `https://rafelolv.github.io/TwitchUsernameChecker/`.
Pages deployment is separate from this release; that address works only after
Pages activation and a successful deployment.

The ZIP contains the static site and MIT license. Extract and serve over HTTP,
for example with `python3 -m http.server 5173`. Open `http://localhost:5173`.
Do not open the modules through `file://`. `SHA256SUMS` verifies the ZIP download.

## Validation

- Five unit cases and JavaScript syntax checks passed locally.
- Chrome 154 desktop/mobile fixture checks covered the four result states,
  validation, persistence, fresh history queries and clearing without JS errors.
- Separate live Chrome checks identified `twitch` as taken and returned
  unconfirmed for an absent test profile.
- Release automation reruns checks and verifies the tag against `package.json`
  before publishing the ZIP and checksums.

## Known limitations

- Twitch's internal API is unsupported and may change or reject requests.
- Live availability checks returned `IntegrityCheckFailed`. Missing profiles
  therefore cannot reliably be classified as available or withheld; the site
  displays unconfirmed and links to Twitch for final confirmation.
- Available/unavailable rendering was verified using simulated responses.
- Firefox, Safari, physical phones, screen readers, real registration and signed-in
  username changes were not checked. Browser fixture tests are separate from live
  Twitch evidence.
