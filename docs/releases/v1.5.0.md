# Twitch Username Checker 1.5.0

A simple, free way to look up Twitch usernames. Use the
[checker](https://rafelolv.github.io/TwitchUsernameChecker/) in your browser, or
serve the static ZIP yourself. No account is needed here.

## What's included

- Single-name checks and lists of up to 350 names, with validation and duplicate removal.
- Compact results with status counts, filters, 20-name pages and copying of available names.
- Stop checking and Continue remaining, keeping completed results and retrying failures only on request.
- English interface, custom @/check mark, responsive layout and light/dark themes with a manual toggle.
- No saved searches, application backend, telemetry or runtime npm dependencies. MIT licensed.

## Future updates

This tool is meant to stay simple, free and useful. Frequent updates and new
features aren't planned. The only planned future update is better username
checking if Twitch introduces an official API that can confirm availability more
accurately. Until then, this version is intended to stay as it is. There is no
update schedule or promised API integration date.

## Availability limits

**Available isn't a guarantee.** A missing profile can appear as Available with
“Not confirmed by Twitch”. Reserved names, renames, suspensions and deactivations
can still prevent you from using it. Sign in to
[Twitch Settings → Profile](https://www.twitch.tv/settings/profile) to confirm.
This tool does not reserve names or predict release dates.

The lookup uses Twitch's unsupported internal endpoint, which may refuse requests
or change. Errors never become Available. The queue stops on a failure or rate
limit; wait before choosing Continue remaining. Successful lookups are not
repeated, while failed rows are replaced when a manual retry succeeds. Editing,
clearing or reloading loses pending work.

## Validation

- JavaScript syntax checks and automated classification/queue tests passed.
- Temporary Chrome profiles on the hosted site: simulated 350-name list, 351-entry
  rejection, 18 pages, filters/counts, copying across pages, cancellation and manual
  continuation. Repeated HTTP 429/500 stopped resumed queues again without losing
  completed results. Reading position and row focus stayed stable during streaming.
- Light/dark and 320px layouts checked with screenshots; README previews refreshed.
- Separate live hosted checks: `twitch` returned an existing account;
  `falsiqkdkdk34` returned unconfirmed absence. Keyboard single-search submission
  and actual clipboard writing/reading worked in a temporary Chrome profile.
- The 350-name checks were mocked, not a live bulk scan. These tests do not prove
  claimability or sustained Twitch throughput. Firefox, Safari, physical phones
  and signed-in username changes were not verified.

## ZIP and checksums

The ZIP contains the static site and MIT license. Extract it, run
`python3 -m http.server 5173` in that folder and open `http://localhost:5173`.
Serve over HTTP rather than opening modules with `file://`.

`SHA256SUMS` contains the ZIP's SHA-256 hash. On Linux, place both downloaded files
in the same folder and run `sha256sum -c SHA256SUMS`.

Website deployment is separate from this tagged release. The release workflow
reruns checks and verifies the tag matches `package.json` before publishing the
reproducible ZIP and checksums.
